Q. What is data ?
It is nothing but meaning full information about data.

Type of data:
1. structure data: arrange in tabular format like in proper format ex. excelsheet or DB table(Relational DB)
2. semi structure data: which is having some structure but not in proper format ex. Json format
3. Unstructured data: which does not having any structured data like Big data ex. video, audio file, facebook feeds with images

Type of database:
a. Relational DB( SQL based database)
b. No SQL DB (non relational database like video, audio files)


Constraints means what kind of data we have to store in a column of table ex. employee_id can not be duplicate so for that we will use primary key
